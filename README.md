# ⚡ SETUP YOUR DAY

A sleek, modern, and lightning-fast To-Do application designed for seamless task management. Built with **React** and **Vite**, styled with **Tailwind CSS**, and brought to life with smooth layout transitions and micro-interactions powered by **Framer Motion**.

## ✨ Features

- **⚡ Instant Performance:** Built on Vite for near-instant build times and fast UI updates.
- **🎨 Modern UI/UX:** Clean, responsive design styled with Tailwind CSS.
- **✨ Fluid Animations:** Smooth task additions, reordering, and completion animations powered by Motion (Framer Motion).
- **💾 Local Storage Persistence:** Automatically saves your tasks locally so your data remains across browser reloads.
- **🎯 Task Filtering:** Easily switch between All, Active, and Completed task views.
- **📱 Fully Responsive:** Optimized for desktop, tablet, and mobile devices.
